are not covered by the MIT licence. The author may publish them separately, for example as a video; any such copy can
be taken down at any time, and no permission is given to use them outside your own private play.

Each music folder holds a `TRACKS.md` listing the exact file names the game looks for and where each song is in that
video; `sound_voices/README.md` does the same for the voice lines. Without the files the game simply plays no music and the Rukka ships say nothing.

## Sounds

covered by the MIT licence.
Some of them stand in for the author's original recordings, which are not included either (all rights reserved, as the
music); the `ORIGINALS.md` beside them names each one's place in the same video.
